라이트/다크 토큰 기반 DS를 단계적으로 컴포넌트별 적용 중. 1~6번은 끝났고 7번부터 미완.

### 완료 (1~6)
- ☑ DS 토큰 기반 확정
- ☑ 타이포그래피 DS
- ☑ 네비게이션(사이드바/탑바) DS
- ☑ 버튼 DS
- ☑ 입력필드 DS
- ☑ 선택컨트롤(체크/라디오/스위치) DS

### 미완 (7~13)
- ☐ 배지/상태칩 DS — 일지의 phase 컬러 칩 / Task 상태 배지 / 새 글 표시 등
- ☐ 탭 DS — 폴더 탭(프로젝트), 필터 탭, 내부 탭
- ☐ 테이블 DS — 일지의 계약·할일 / 직원 목록 / 회의록 목록
- ☐ 카드/KPI + CRM 컬러셋 DS — 대시보드 4박스, 프로젝트 카드
- ☐ 알림/모달/토스트 DS — 액션 팝업, 확인 모달, 토스트
- ☐ 아바타/프로그레스/아이콘 DS — Avatar 컴포넌트, 진행률 바
- ☐ 차트/데이터뷰 DS — 대시보드 차트 (아직 차트 거의 없음)

### 진행중 (14)

  - 글로벌 `!important` 룰 점진적 제거

## 알려진 이슈

### 1. 글로벌 `!important` 룰
- `src/styles.css`에 `input, select, textarea { background: var(--panel) !important; }` 등 존재
- 일지의 status select가 색상 칩으로 보이려고 했을 때 충돌 → button + 팝오버로 우회됨
- 추후 DS 정리 시 글로벌 룰 자체를 클래스 기반으로 좁히면 우회 코드 정리 가능

### 2. 멀티 세션 / SMB 충돌
- SMB 공유 폴더로 여러 머신에서 동시 편집 → 같은 파일 충돌 가능
- 작업 전 `git pull` 필수, 큰 작업 시 통신 협의

### 3. 자동배포 시점
- `main` 푸시 후 자동배포까지 30~60초
- 빌드 메타가 새 커밋으로 바뀌었는지 `curl /build-meta.json`로 확인

### 4. 모바일 푸시 — iOS 한정
- iOS Safari Web Push는 PWA 설치 시에만 동작 (사용자가 홈 화면에 추가해야)
- Capacitor 빌드 앱은 APNs로 동작 (별도 인증서 필요)

### 5. Google Calendar 동기화
- OAuth 인증 갱신 처리 부분 점검 권장 (refresh token 만료 케이스)
- `sync-google-calendar` Edge Function 로그 주기 모니터링

### 6. 시드 데이터 prototype mode
- 환경변수 없으면 `userId='prototype'` 시드만 보임
- 실제 직원 시드(`userId='1'`, `'2'` 등)는 안 보임 — 의도된 동작
