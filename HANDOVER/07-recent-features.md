# 07 — 최근 추가된 주요 기능

(최근 ~25 커밋 기준, 인수 전 약 한 달간 작업)

## 주간업무일지 (Journal) — 신규 메뉴
사이드바 맨 아래(캘린더 밑), 굵게 강조 표시.

### 구조
- 주차 네비게이터(월~일 ISO 표준), 오늘 기준 자동 표시
- **상태 팔레트**: 28종 시드(시트 우측 상단 미러), 커스터마이징 가능(이름/색상/추가/삭제)
- **이번주 진행중 계약·할일** 표: 순번/상호·업무/진행상황/기타사항
- **일별 로그**: 월요일~일요일 그룹, 각 행에 종류·제목·기타사항·프로젝트매칭·상태
- **인라인 편집 UX**: 텍스트로 보이다가 셀 클릭 → 인풋·체크버튼 등장 → 저장
  - 텍스트(제목/기타사항): 인풋 + ✓
  - 종류·상태: 색상 칩 그리드 팝오버 (native select가 글로벌 `!important` 룰과 충돌해서 우회)
  - 프로젝트 매칭: select 드롭다운
- **드래그-이동/복사**: 그립 핸들 잡고 다른 날짜로 끌면 이동, **Ctrl(Cmd)+드래그**는 복사
  - PC: 마우스 즉시 드래그
  - 모바일: 280ms 롱프레스 + 햅틱
  - ghost UI에 "＋ 복사" 뱃지로 모드 표시
- **직원 일지 보기**: 팔레트 바 우측 셀렉터에서 다른 직원 일지 읽기전용 열람
- **키보드 네비게이션**: Enter로 다음 필드, 화살표 키로 칩 픽커 이동

### 데이터 모델 (Supabase)
- `journal_entries` — 항목별 (userId, weekStart, date, kind, title, detail, status, projectId, ...)
- `journal_status_palette` — 직원별 커스텀 상태
- `journal_kinds` — 직원별 커스텀 종류
- `weekly_contracts` — 이번주 진행중 계약·할일

자세한 마이그레이션은 `supabase/migrations/20260527140000_journal.sql`, `20260527160000_journal_kinds.sql`.

## 캘린더 — 업데이트
- 담당자 드롭다운 필터 (전체 / 나 제외 / 직원별)
- 색상 범례 5종 표시 (받은 업무 파랑 / 보낸 업무 회색 / 완료 초록 / 구독·정산 주황 / 개인 스케줄 없음)
- 완료 업무는 초록 좌측 컬러바
- 개인 스케줄은 좌측 컬러바 없음
- 직원의 개인 스케줄도 같은 담당자 필터로 필터링 (이름 매칭)

## 업무 — 계획 시작일 (startAt)
- `tasks.start_at` 컬럼 추가 — 마감일과 짝
- 캘린더에 기간 막대로 표시 (start_at ~ due_at)
- 마이그레이션: `20260528000000_tasks_start_at.sql`

## 모바일 스와이프 좌우 페이지 전환
- 손가락 1:1로 따라오는 슬라이드
- destination 뷰 미리보기 + 트래킹 weight
- 글자 선택 중에는 차단 (영역 기반)

## 로그인 후 뒤로가기 가둠
- 로그인 / "확인 중..." 화면으로 뒤로 못 가게 함 (모바일 뒤로가기 키 / 브라우저 백 버튼)

## UI 다듬기
- 새 글 배지·활성 표시: 노란색 → 빨간색
- 사이드바 스크롤바 숨김 (다크모드 흰 thumb 문제)
- 전역 텍스트 선택 차단 + 게시물 본문/댓글만 허용

## 날짜 입력 통일
- 모든 날짜 필드를 클릭 즉시 열리는 **커스텀 달력**으로 통일 (native date input 대신)
